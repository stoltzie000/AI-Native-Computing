# AI-Native-Computing
Research and development of a next-generation AI-native computing architecture, including purpose-built processors, memory systems, motherboard design, interconnects, and software, engineered from first principles to outperform conventional GPU-based AI computing.

## Engineering status (2026-11-23)

The first reproducible research simulator is available at [simulator_v0_2](simulator_v0_2/README.md). It models fast/bulk memory traffic, KV-cache movement, compute ceilings, capacity, multi-node fabric overhead, and a simple physical SRAM area limit. An isolated local run passed **21/21 tests**. A GitHub Actions regression workflow is configured but its execution status is not yet confirmed.

**No superior physical AI processor has been demonstrated.** The optimistic SRAM-based candidate requires wafer-scale or multi-chiplet integration and real electrical/thermal verification. Simulated scenario throughput must not be interpreted as measured hardware performance.

See [product definition](docs/PRODUCT_DEFINITION.md), [validation protocol](docs/VALIDATION_PLAN.md), [project state](PROJECT_STATE.md), and [physical feasibility screen](simulator_v0_2/docs/PHYSICAL_FEASIBILITY_SCREEN.md).

**Evidence level:** E1 analytical/transaction-dependency simulation with a small numerical functional test. In an isolated Python environment **43/43 unit tests passed**, and the report regenerated byte-identically. Published GPU memory specifications are used only as input ceilings; v0.3's output rates are **not measured hardware performance**. A new AI processor, custom motherboard, or experimentally verified advantage against a GPU has **not** been demonstrated. Continue with physically calibrated link, power, packaging and task-quality experiments.

## Physically bounded network/topology simulator v0.4 — 2026-11-23

[Simulator and tests](simulator_v0_4/README.md) · [Hardware evidence boundaries](simulator_v0_4/docs/PHYSICAL_BOUNDARIES.md) · [Failure-analysis ledger](simulator_v0_4/docs/TOPOLOGY_REVIEW.md) · [Deterministic result report](simulator_v0_4/results/summary.json) · [Regression workflow](.github/workflows/simulator-v0-4-tests.yml).

v0.4 adds explicit point-to-point physical link limits, route-dependent latency, port-count rejections, and small CPU recursive-doubling numerical correctness tests. In an isolated runtime 24/24 v0.4 tests and 43/43 existing v0.3 tests passed. All 11 v0.4 files uploaded to GitHub were verified against local copies by Git blob SHA. These are **hypothetical E1 scenario calculations**, not measured physical AI hardware or evidence of defeating a current GPU. The next gates remain physical link characterization, energy/area/thermal budget and matched GPU validation.
